# P2P Project - Local Claude Configuration

This directory contains project-specific files for the P2P project.

## Structure

- `plans/` - Project plans and specifications
- `tasks/` - Task definitions and progress
- `specs/` - Technical specifications
- `steering/` - Project context and conventions
- `todos/` - Project todo items
- `archive/` - Archived project files

## Global Configuration

All agents, commands, and hooks are located in `~/.claude/`

Use slash commands like `/commit`, `/orchestrate`, `/plan` from the global configuration.
