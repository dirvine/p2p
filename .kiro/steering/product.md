# Product Overview

## P2P Foundation

A next-generation peer-to-peer networking foundation built in Rust, featuring QUIC transport, privacy-first identity system, and fully integrated AI capabilities through Model Context Protocol (MCP) servers at each node.

### Key Products

- **Saorsa Core Library** (`saorsa-core` on crates.io): The foundational P2P networking library
- **Saorsa Desktop App**: Tauri-based desktop application for encrypted messaging and P2P communication
- **Terminal Apps**: CLI tools for network testing and chat functionality

### Unique Features

- **Four-Word Network Addresses**: Human-readable networking like `forest.lightning.compass.river`
- **Quantum-Resistant Security**: ML-KEM-768 and ML-DSA-65 (FIPS 203/204) for future-proof cryptography
- **Threshold Cryptography**: FROST protocol for multi-party authorization and group management
- **Git-Like DHT**: Universal version control with BLAKE3 hashing and network-wide deduplication
- **AI-Native Architecture**: MCP server integration with distributed AI tool orchestration
- **Zero-Friction Onboarding**: Voice-shareable addresses eliminate technical barriers

### Target Use Cases

- Decentralized messaging and communication
- Peer-to-peer file sharing and collaboration
- Distributed AI service orchestration
- Privacy-first social networking
- Enterprise-grade secure communications
